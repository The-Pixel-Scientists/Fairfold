# Security policy

PixelGrant handles personal data about applicants, reviewers and staff. We
take every report seriously and aim to respond quickly.

## Reporting a vulnerability

Report privately through GitHub: open this repository's **Security** tab and
choose **Report a vulnerability**. Please do not open a public issue, pull
request or discussion about it.

Include:

- what you found and where (file, endpoint or screen)
- steps to reproduce, using synthetic data only
- the impact you think it has

## What to expect

| Step | Target |
| --- | --- |
| Acknowledge your report | 3 working days |
| Initial assessment and severity | 10 working days |
| Fix for a critical issue | 14 days |
| Fix for a high issue | 30 days |

We will keep you updated, agree a disclosure date with you, and credit you in
the release notes unless you would rather not be named.

## Supported versions

PixelGrant is pre-release. Only the `main` branch is supported, and it must
not be used with live personal data yet.

## Scope

In scope: the code in this repository.

Out of scope: deployments run by other organisations (report those to the
operator), social engineering, denial of service, and anything that needs
physical access to a user's device.

## Safe harbour

We will not take action against good-faith research that follows this
policy, avoids privacy violations and service disruption, and uses only
accounts and data you own or synthetic data.
