# Fairfold Forms

**Planned: work is due to start in 2028.** Nothing is built here yet.

Forms and surveys for feedback, registrations and more, built on the same form
engine as grant applications.

Fairfold Forms will be a module of the Fairfold suite, sharing its record of
organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `forms`.
