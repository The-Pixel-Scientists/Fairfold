# Modules

One folder per Fairfold tool, named by its code name. A module owns its own
database schema and talks to the others through published contracts
([ADR 0016](../docs/adr/0016-modular-suite-and-shared-warehouse.md)).

Fairfold Grants and the shared record of organisations and people are being
built now. The other folders are placeholders for planned tools; the
[project README](../README.md#the-fairfold-suite) lists them all.
