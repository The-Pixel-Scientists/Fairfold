# Fairfold Fund Accounting

**Planned: work is due to start in 2028.** Nothing is built here yet.

Restricted and unrestricted funds, budgets and commitments, so a finance team
can see what is spent and promised against each fund.

Like every Fairfold tool, Fairfold Fund Accounting will work on its own or
alongside the others. It will run on the shared platform: accounts and
permissions, an audit log, the shared record of organisations and people, and
the data warehouse. See the [project README](../../README.md) for the whole
suite and what is built today.

Code name: `funds`.
