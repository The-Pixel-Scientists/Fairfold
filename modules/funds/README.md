# Fairfold Fund Accounting

**Planned: work is due to start in 2028.** Nothing is built here yet.

Restricted and unrestricted funds, budgets and commitments, so a finance team
can see what is spent and promised against each fund.

Fairfold Fund Accounting will be a module of the Fairfold suite, sharing its
record of organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `funds`.
