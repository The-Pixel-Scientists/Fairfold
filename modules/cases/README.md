# Fairfold Case Management

**Planned: work is due to start in 2028.** Nothing is built here yet.

Casework for service teams: referrals, assessments, plans and outcomes for the
people a charity supports.

Fairfold Case Management will be a module of the Fairfold suite, sharing its
record of organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `cases`.
