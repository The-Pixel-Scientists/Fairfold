# Fairfold Governance

**Planned: work is due to start in 2027.** Nothing is built here yet.

Trustee boards, board packs, decisions, conflicts of interest, risks, policies
and incidents in one place.

Fairfold Governance will be a module of the Fairfold suite, sharing its record
of organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `governance`.
