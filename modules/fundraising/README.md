# Fairfold Fundraising

**Planned: work is due to start in 2028.** Nothing is built here yet.

Supporters, donations, Gift Aid and campaigns, for charities that raise money
as well as give it.

Fairfold Fundraising will be a module of the Fairfold suite, sharing its
record of organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `fundraising`.
