# Fairfold Impact

**Planned: work is due to start in 2027.** Nothing is built here yet.

Outcomes, indicators and evidence from grants and activities, so trustees can
see what difference the money makes.

Fairfold Impact will be a module of the Fairfold suite, sharing its record of
organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `impact`.
