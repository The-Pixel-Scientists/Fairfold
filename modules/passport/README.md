# Fairfold Organisation Profile

**Planned for 2029 or later.** Nothing is built here yet.

An organisation's details, given once and reused with every funder it applies
to.

Fairfold Organisation Profile will be a module of the Fairfold suite, sharing
its record of organisations and people, its accounts and permissions, and its
data warehouse. See the [project README](../../README.md) for the whole suite
and what is built today.

Code name: `passport`.
