# Fairfold Organisation Profile

**Planned for 2029 or later.** Nothing is built here yet.

An organisation's details, given once and reused with every funder it applies
to.

Like every Fairfold tool, Fairfold Organisation Profile will work on its own
or alongside the others. It will run on the shared platform: accounts and
permissions, an audit log, the shared record of organisations and people, and
the data warehouse. See the [project README](../../README.md) for the whole
suite and what is built today.

Code name: `passport`.
