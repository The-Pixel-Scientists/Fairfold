# Fairfold Field App

**Planned: work is due to start in 2027.** Nothing is built here yet.

A mobile app for work away from the office, such as monitoring visits, that
keeps working without a signal.

Like every Fairfold tool, Fairfold Field App will work on its own or alongside
the others. It will run on the shared platform: accounts and permissions, an
audit log, the shared record of organisations and people, and the data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `field`.
