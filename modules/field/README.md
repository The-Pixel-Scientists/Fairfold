# Fairfold Field App

**Planned: work is due to start in 2027.** Nothing is built here yet.

A mobile app for work away from the office, such as monitoring visits, that
keeps working without a signal.

Fairfold Field App will be a module of the Fairfold suite, sharing its record
of organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `field`.
