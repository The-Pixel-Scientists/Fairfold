# Fairfold Assistant

**Planned for launch in 2027.** Nothing is built here yet.

A governed assistant that helps staff draft, summarise and find things, and
leaves every decision to people.

Fairfold Assistant will use the same MCP server and controls as AI agents
connected through [Fairfold Integrations](../connect).

Like every Fairfold tool, Fairfold Assistant will work on its own or alongside
the others. It will run on the shared platform: accounts and permissions, an
audit log, the shared record of organisations and people, and the data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `assist`.
