# Fairfold Assistant

**Planned: work is due to start in 2028.** Nothing is built here yet.

A governed assistant that helps staff draft, summarise and find things, and
leaves every decision to people.

Fairfold Assistant will be a module of the Fairfold suite, sharing its record
of organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `assist`.
