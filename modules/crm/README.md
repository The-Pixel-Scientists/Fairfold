# Fairfold CRM

**Planned: work on the full CRM is due to start in 2027.** Nothing is built here yet.

Organisations, people, relationships and consent, recorded once and shared by
every Fairfold tool. The core of it, the shared record of organisations and
people, is part of the first release of Fairfold Grants; the full CRM builds
on that record.

Fairfold CRM will be a module of the Fairfold suite, sharing its accounts and
permissions and its data warehouse, and providing the record of organisations
and people that every tool uses. See the [project README](../../README.md) for
the whole suite and what is built today.

Code name: `crm`.
