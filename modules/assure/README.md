# Fairfold Due Diligence

**Planned: work is due to start in 2027.** Nothing is built here yet.

Checks on applicants and grantees: registry lookups, sanctions screening,
fraud and safeguarding checks, and monitoring visits.

Fairfold Due Diligence will be a module of the Fairfold suite, sharing its
record of organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `assure`.
