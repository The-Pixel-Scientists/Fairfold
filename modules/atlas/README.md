# Fairfold Funding Map

**Planned for 2029 or later.** Nothing is built here yet.

Who funds what, and where, built from open grants data.

Fairfold Funding Map will be a module of the Fairfold suite, sharing its
record of organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `atlas`.
