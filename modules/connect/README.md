# Fairfold Integrations

**Planned for launch in 2027.** Nothing is built here yet.

A plugin API and connections to other systems, with tools to bring data in
from what you use today.

Fairfold Integrations will also include an MCP (Model Context Protocol)
server, so your AI agents can work with Fairfold while you stay in control.
Agent access is off until you switch it on. Each connection acts for a named
person, with no more than their permissions, and can only read unless you
allow more. Equality monitoring answers and other special category data are
kept out by default. No agent ever makes a decision: agents can find,
summarise, draft and propose, and a person decides in Fairfold. Every action
is logged, so you can see what each agent did, and you can switch any
connection off.

Like every Fairfold tool, Fairfold Integrations will work on its own or
alongside the others. It will run on the shared platform: accounts and
permissions, an audit log, the shared record of organisations and people, and
the data warehouse. See the [project README](../../README.md) for the whole
suite and what is built today.

Code name: `connect`.
