# Fairfold Integrations

**Planned: work is due to start in 2027.** Nothing is built here yet.

A plugin API and connections to other systems, with tools to bring data in
from what you use today.

Fairfold Integrations will be a module of the Fairfold suite, sharing its
record of organisations and people, its accounts and permissions, and its data
warehouse. See the [project README](../../README.md) for the whole suite and
what is built today.

Code name: `connect`.
