# Fairfold Integrations

**Planned: work is due to start in 2027.** Nothing is built here yet.

A plugin API and connections to other systems, with tools to bring data in
from what you use today.

Like every Fairfold tool, Fairfold Integrations will work on its own or
alongside the others. It will run on the shared platform: accounts and
permissions, an audit log, the shared record of organisations and people, and
the data warehouse. See the [project README](../../README.md) for the whole
suite and what is built today.

Code name: `connect`.
