# AI-assisted contributions

This project uses AI coding agents alongside human engineers.

- AI-assisted code is welcome and held to exactly the same standards as any
  other contribution.
- Every commit carries a Developer Certificate of Origin sign-off from a named
  human, who certifies they have reviewed the change and have the right to
  submit it.
- A human reviews and merges every pull request. Changes to authentication,
  row-level security, the audit log, migrations and data export always get
  line-by-line human review.
- Agents never have access to secrets, production systems or real personal
  data.
- Agent configuration is kept outside the repository. The standards agents
  work to are the same ones in this repository's contributing guide,
  definition of done and architecture decision records.
