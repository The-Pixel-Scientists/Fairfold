# Forms

Forms is for surveys and registrations built on the same form engine as grant
applications. It is not yet available. See the
[module README](../../../modules/forms/README.md).

On 19 November 2026 the module has a manifest and empty server, console and
portal folders. Its classification file is empty: it has no tables and holds
no personal data.

## Personal data it holds

None yet. When tables arrive, the records of processing will list them.

## Controls beyond the platform baseline

Not yet available. The platform's design rules will apply: answers keyed by
stable field ids, and a form version pinned at submission. Anonymous public
submissions are covered by
[ADR 0036](../../adr/0036-anonymous-public-submissions.md), which is still
proposed.

## Row-level security and audit

Not yet available. Any new table needs a policy and a cross-tenant denial
test before it merges.
