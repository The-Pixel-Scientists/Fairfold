# Administrator guide

This guide is for the person who runs a funder's account in Fairfold Grants.
In the software that person has the **Administrator** role. You do not need to
be technical. If you also run the servers, see the
[self-hosting quickstart](../self-hosting/quickstart.md).

## What an administrator can do

You can:

- set your funder's name, time zone, logo and colours;
- switch modules on and off;
- invite people to your team, change their roles, suspend them and remove them;
- save your 360Giving publisher details;
- download your data and read the audit log.

You cannot:

- reset another person's password or authenticator app. Ask the operator,
  who runs the service for you;
- create a funder. The operator does that;
- record or release decisions, unless you also hold the **Programme manager**
  role. See [Releasing decisions](releasing-decisions.md);
- read applications, unless you also hold the **Programme manager** role.

The guide calls the people who run the software the operator. For the managed
service that is The Pixel Scientists. If you host it yourself, it is whoever
looks after your servers.

## How the guide is written

Button and page names are in **bold**, exactly as the screens show them. All
names, organisations and identifiers in examples are invented. The guide
describes the software as it is today, not as planned.
